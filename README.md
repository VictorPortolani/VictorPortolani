### 👨‍💻 Sobre Mim

Sou um desenvolvedor em formação e meu foco é resolver problemas no **Back-end**. Gosto de construir a lógica e fazer as engrenagens funcionarem por trás da tela. 

Atualmente trabalho mais focado com **C#** e **Java**, lidando com regras de negócio e banco de dados. Quando o projeto exige, também coloco a mão no Front-end para entregar a aplicação completa.
